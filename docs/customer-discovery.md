# Customer discovery: interview script and pilot scorecard

For bordereaux technicians, claims/operations managers and compliance leads at coverholders, MGAs and
delegated claims administrators. 30 minutes. Ask, then listen; don't pitch until the last five minutes.

## Before the call
- Note the firm's size, lines of business and which managing agents/insurers they report to.
- Ask them to have a recent (anonymised) bordereau to hand, if they're willing.

## The 10 questions

1. **Volume.** How many bordereaux do you send (or receive) a month? Claims, premium or both? How many
   different recipients, each with their own template?
2. **Time.** Walk me through the last one you prepared. How many hours, from export to sending? Who did it?
3. **Returns.** How often does a file come back from the managing agent or insurer? What happened the last
   time? How long did the fix take?
4. **Worst errors.** Which errors keep coming back? (Arithmetic that doesn't add up, missing policy numbers,
   duplicates, wrong currency, dates, statuses, losses outside the policy period...) Which one hurts most?
5. **Current tools.** What do you use today to check a file before it goes out? Excel formulas, macros, a
   colleague's second look, a platform? What do you like and hate about it?
6. **Sign-off.** Who signs off a bordereau before it's sent? What do they check? What would they need to see
   to trust an automated check?
7. **Data security.** What proof would your compliance team need before you upload claims data? (Where it's
   hosted, retention, encryption, a DPA, ISO 27001/SOC 2, pen test, references.)
8. **Price.** What does a returned file cost you in time? What would you pay to never have one returned:
   per file, per month? Who holds that budget?
9. **Switching.** What would make you switch from what you do today? What would stop you?
10. **Referrals.** Who else should I talk to: someone at another coverholder, or at the managing agent who
    receives your files?

## Close (last five minutes)
Offer the founding pilot: "Send me one real bordereau; I'll return the annotated workbook, a corrected copy
and a query letter within a day. First file free." Agree a date.

## Pilot scorecard (one per pilot customer)

| Measure | Before TrueBind | With TrueBind | How measured |
|---|---|---|---|
| Time to prepare and check one bordereau (hours) | | | Customer's own estimate, then timed |
| Errors caught before sending | | | TrueBind findings the customer agrees were real |
| False alarms (findings the customer rejected) | | | Count; target under 10% of findings |
| Files returned by the managing agent / insurer (last 3 months vs pilot period) | | | Customer's records |
| Time to fix a returned file (hours) | | | Customer's estimate |
| Would they pay? How much, per file / per month? | — | | Direct question at the end of the pilot |
| Would they recommend us? (0–10) | — | | Direct question |
| Blockers to buying (security, price, sign-off) | — | | Notes |

A pilot is a success if the customer agrees errors were caught that would otherwise have been returned, the
false-alarm rate is under 10%, and they name a price.
